## 🧠 How the search flow works

The project is made to support a simple search path:

1. A tool reads the skill file.
2. The skill tells it how to search TokRepo content.
3. The tool finds the best match.
4. The user gets a result that can be used in the current task.

This helps cut down on repeated manual searching and keeps the process steady across tools.
